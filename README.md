# 사각사각 · Sagak-Sagak

**▶ 플레이: https://greverse9.github.io/latin-square-fusion-play/**

연필이 종이에 닿는 소리, 그리고 4×4 사각(四角) 판.
종이 스도쿠의 추론과 단계 성장을 합친, 눈이 편안한 모바일·태블릿 퍼즐입니다. 시간 제한은 없습니다.

## 규칙 한눈에
- 아래 타일을 탭해 고르고, 빈칸을 탭해 놓아요.
- 같은 가로줄·세로줄에는 같은 기호를 둘 수 없어요.
- **2×2 구역**에 서로 다른 4개가 모이면 ★가 자라고, ★가 든 구역을 다시 채우면 👑이 돼요.
- 가로·세로 **줄**은 가득 차면 지워지기만 해요(줄 안의 ★도 사라져요).
- 목표를 **남은 수** 안에 채우세요. 스테이지 30개 · 끝없는 도전 · 오늘의 퍼즐.

## 의견 보내기
게임 안 **메뉴 → 의견 보내기**를 누르면 버전과 기기 정보가 채워진 양식이 열려요. 직접 남기려면 [이슈 작성](https://github.com/greverse9/latin-square-fusion-play/issues/new/choose)에서 양식을 고르세요(GitHub 계정 필요). 반영되면 해당 이슈에 버전과 함께 알려 드려요.
